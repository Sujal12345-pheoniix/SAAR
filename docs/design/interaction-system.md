# SAAR — Interaction System & Behavioral UX

## 1. Interaction First Principles

1. **Every Interaction Must Be Real**:
   - Every button, toggle, slider, and selector either updates persistent state, executes a meaningful simulation, navigates to a real surface, or does not exist.
   - Fake interactivity, unlinked buttons, and static mock screenshots masquerading as interfaces are strictly prohibited.
2. **Context Over Raw Numbers**:
   - No floating percentages without comparative meaning (e.g. `84% • Stable 14-day regularity`).
3. **Discoverable Evidence (Trust Architecture)**:
   - When SAAR provides an observation or insight, it must never be an unchallengeable assertion.
   - Every claim is accompanied by an inspectable evidence drawer displaying the raw data points, time windows, and comparative baselines.
4. **Transparent Trade-offs Over Guilt**:
   - SAAR never chides the user for incomplete work. When an evening is overloaded, it illustrates the physiological trade-off (Work ↕ Recovery) and empowers the user to choose an adjustment.

## 2. Signature Interactions

### A. The Becoming Field
* **Purpose**: Dynamically visualizes how small daily calibrations alter the distance between Today's reality and the Future Self.
* **Mechanism**: An interactive multi-stage slider that synchronizes daily schedule status, routine friction, alignment percentage, and projected long-term trajectory.
* **User Feedback**: Smooth spring animations, live recalculation of the behavioral gap (from 52% down to 4%), and contextual trajectory shifts.

### B. Orbital Life Intelligence Ecosystem
* **Purpose**: Demonstrates that life is an interconnected biological system rather than six isolated to-do lists.
* **Mechanism**:
  - Central node (You / Holistic Equilibrium).
  - 6 Orbital Nodes (Health, Mind, Career, Relationships, Purpose, Finance) using minimal, human SVG glyphs (zero emojis).
  - Reciprocal Connection Lines: Selecting an area (e.g. Health) instantly highlights its direct dependencies (Mind for focus, Career for energy).
  - Coordinated Panel Response: The detail pane updates dynamically with active destination goals, recent 14-day patterns, and a high-leverage next action.

### C. The Adaptive Planner Simulator
* **Purpose**: Teaches capacity consciousness by allowing users to interactively resolve an overloaded day.
* **Mechanism**:
  - Live capacity gauge calibrated to 450 minutes (7h 30m sustainable human focus).
  - Real-time recalculation of total minutes and overload warnings.
  - Interactive Action Controls:
    - `[Condense]`: Reduces secondary task duration by 40% to protect core outcomes.
    - `[Move →]`: Shifts non-essential items to tomorrow with instant strike-through feedback.
    - `[Reset Plan]`: Restores baseline for continuous exploration.
  - Live Trade-off Gauge: Visualizes the shifting balance between Craft Output and Vital Recovery.

### D. Grounded Companion & The SAAR Pulse
* **Purpose**: Provides AI companionship that feels quiet, respectful, and grounded in behavioral truth.
* **Mechanism**:
  - **The SAAR Pulse**: An organic, breathing concentric SVG ring that indicates active listening and contemplation.
  - **Contextual Inquiries**: Users select or enter real inquiries into execution patterns.
  - **Discoverable Evidence Drawer**: An interactive accordion revealing verified telemetry metrics behind each response.
  - **Action Proposal Cards**: Any schedule modification proposed by the companion is rendered as a standalone card requiring explicit user confirmation before applying.
